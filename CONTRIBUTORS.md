# Contributors

Thank you to everyone who has contributed links, fixes, and suggestions to this repository — your help keeps it accurate and useful.

How to be listed

- Option A — Preferred: Open a Pull Request that adds a single line to this file using the format below.
- Option B: Open an Issue with your name, GitHub handle, short contribution note, and a maintainer will add you.

Entry format (one per line)

- @github-handle — short note (e.g., "curated scholarships", "added Postdoc links", "fixed broken links") — YYYY-MM-DD
